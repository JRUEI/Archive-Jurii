# 逢田珠里依 SHOWROOM 2026/09/03

## 【精簡總結】

* 開場她被禮物洗版，一路喊了幾十次「停」還是攔不住，還說「我現在腦袋真的完全沒在運作」，最後改用投票模式。
* 投票數字設成 10，因為距離寫真集發售剛好十天——而她是看到有人做的倒數影片，才發現那也是距離生日十天。
* 她說實體書自己還沒看到，成員也還沒看到。20 歲的最後一天要工作，「很開心喔。能跟成員在一起」。
* 聊到酒，她說自己大概喝得了但不會喝，理由是「我是膽小鬼」——聽說喝了會變得不像自己，「那不是很可怕嗎。當偶像的話」。但她很想看大家喝醉的樣子，甚至說得快點讓 LINK 變成能傳照片和影片的系統。
* 她昨天自己剪了瀏海，剪出大事。她也說偶爾會幫山田杏佳剪瀏海，一直在演要杏佳在照片上 tag 她的梗，「因為杏佳的瀏海也是我剪的啊」。
* 她說「沒有要剪齊瀏海的預定。全日本最不適合」，瀏海也不會留長；頭髮不放下來的話，她就不想露額頭。
* 雙馬尾跳舞時，一轉圈頭髮就甩過來；她喜歡有光澤的唇釉，頭髮會黏上來，那段編舞剛好是擦眼淚的動作，她就一邊做一邊撥頭髮，一邊想「走開走開別過來」。
* 她出題讓大家猜這輩子絕對一次都不會做的髮型，正解是「這個高度的丸子」、熊耳，也就是雙丸子；化妝師也說「的確，珠里依可能不是走那個路線的」。她說自己希望頭髮是會晃動的。
* LINK 的反向提問她全部看完了，包括昨天演唱會開演前大概三分鐘有人傳來的。她說「什麼時候知道我的、什麼時候變成喜歡的」的回答滿有趣的；回答裡也有滿多是大家的感情狀況。
* 香水她說是 Margiela 的，但想不起是哪一支，只記得買來的盒子上好像有紫色，承諾隔天一定在 LINK 上公布。
* 後半是 Tower 點名，從第一名的ふかちゃん開始一位一位叫名字、回應留言，中途聊到石川、大宮、生誕祭與各種約定。

### [18:39] [髮型] 自己剪壞的瀏海與杏佳的瀏海

她說瀏海長長了，昨天隨便自己剪結果出大事。她也說偶爾會幫山田杏佳剪瀏海，一直在演要杏佳在照片上 tag 她的梗。

### [20:17] [髮型] 偏長的瀏海設定

她說自己的瀏海是偏長的設定，給成員看都被說明明還很長。她自稱是全日本最不適合齊瀏海的人，瀏海也不會留長。

* **偏長的設定**：她說每次跟成員說「剪太多了」拿給她們看，都會被說「明明還很長啊」，因為有些成員是齊瀏海、幾乎不燙、剪在眉毛正上方；她自己是蓬鬆地捲一下、落在眉毛下面，「比大家都長」。
* **現在的長度**：她說剛剪完所以算短的，日常剛剛好，不過要演唱會的話還是偏長。
* **齊瀏海**：她說「沒有要剪齊瀏海的預定，全日本最不適合」，剪齊瀏海真的會顯胖；「與其說想要偶像瀏海，是因為齊瀏海不適合我才留偶像瀏海」。
* **不會留長**：她說瀏海不會留長，還問「『留長瀏海』是指什麼？是指變成沒有嗎？像結香那樣的？」，接著說「結香才是真的臉小」。

### [21:48] [髮型] 額頭與往上盤

她說瀏海能守護額頭，可是一流汗就會跑出來。天氣熱也想全部往上盤，但新生髮際線那一帶會全開，有點害羞。

* **額頭**：她說瀏海能守護額頭，可是流汗就會跑出來；巡演的某一場也許會露額頭，「不過我頭髮不放下來的話就不想露額頭」。
* **想往上盤**：她說也有想做往上盤的心情，可是新生的髮際線那一帶比較空，往上盤的話會全開，「有點害羞」。
* **留一點下來**：她說因為熱想全部盤起來，可是盤起來脖子那邊又太空，所以要留一點下來，「這很麻煩的」「髮型會越來越少喔」；「馬尾之類的從正面看也什麼都沒有嘛」。
* **杏佳的美髮師**：她笑說「我是杏佳的美髮師」。

### [24:29] [髮型] 雙馬尾很難跳

她說雙馬尾很難跳，一轉圈頭髮就甩過來黏在唇釉上，那段編舞剛好是擦眼淚的動作，她就一邊做一邊撥頭髮。馬尾和半丸子也各有麻煩。

* **雙馬尾很難跳**：她說自己習慣的髮型最好跳，雙馬尾因為太少做，一轉圈頭髮就甩過來；她現場重演了一次，說一邊轉一邊喊「走開啦走開啦」「別過來這邊」，「好礙事」。
* **是哪一首**：她想了一下是哪一首的編舞，說出〈無防人〉。
* **黏在嘴上**：她說自己喜歡有光澤的唇釉，頭髮會直接黏上來；那段編舞剛好是擦眼淚的動作，她就「一邊做擦眼淚的動作、一邊把頭髮撥開地跳」，「真的很討厭，很難回到原位」，所以平常就綁雙馬尾跳舞的人真的很厲害。
* **馬尾與半丸子**：她說馬尾反過來會有一整束打過來；平常都綁雙馬尾的人好像反而覺得放下來很難跳。她本來以為半丸子最輕鬆，可是 K Arena 那次跳起來超級困擾，「幾乎跳不起來」，會「啪」地一下。

### [27:59] [髮型] 這輩子大概不會做的雙丸子

她出題讓大家猜這輩子不會做的髮型，答案是雙丸子（熊耳），說不適合的未來看得見，化妝師也同意。她希望頭髮是會晃動的。

* **出題**：她說有一個這輩子絕對一次都不會做的髮型，「猜得到嗎」，說常跟化妝師聊這個；有正式名稱，是髮型編法，不是長度。
* **不是波堤獅頭**：她說波堤獅頭很多人說喜歡，「目前沒有預定，不過也沒有發誓不做」；水母頭她倒是做過。
* **答案**：正解是「這個高度的丸子」、熊耳，也就是雙丸子。她說「真的已經、已經、已經看得見了」「這在日本偶像界我大概是最不適合的」，有人說才沒有那種事，她說「真的有這種事喔，真的救命」，「所以波堤獅頭對我來說比雙丸子安全」。
* **化妝師也同意**：她說跟化妝師講的時候，對方說「的確，珠里依可能不是走那個路線的」，她回「就是說啊」。
* **她的偏好**：她說「我希望頭髮是會晃動的」；影像作品的時候會放下來，演唱會不綁起來的話，因為很會流汗會很辛苦。

### [30:59] [LINK] 反向提問的收穫

她說 LINK 反向提問的回答全部都看過了，開演前大概三分鐘還在看。覺得有趣的是大家什麼時候知道她、什麼時候喜歡上她，也知道了不少人的感情狀況。

* **喜歡的髮型**：她說 LINK 上說喜歡馬尾的人可能最多，因為夏日祭典才喜歡上她的人則多半喜歡雙馬尾，「我借了大家的勇氣綁了雙馬尾」；也有人喜歡直髮、捲了放下來的。
* **全部看完了**：她說「全部都過目了」，昨天演唱會開演前大概三分鐘有人傳來，她還在看。
* **有趣的部分**：她說「什麼時候知道我的、什麼時候變成喜歡的」的回答滿有趣的：有人知道跟喜歡是同時的，也有人很久以前就知道、甚至去過演唱會，但當時沒有特別入坑，最近才喜歡上、現在超常來看演唱會。
* **感情狀況**：她說也知道了不少人的感情狀況，還有「欸你結婚了喔」這種；看到有人說「最喜歡珠里依」很開心，也有人說「想讓珠里依當戀人」，「我很榮幸」。

### [34:12] [美妝] 疊在腮紅上的粉紅打亮

她說臉上的光澤來自リリミー的粉紅打亮，總是疊在腮紅上，鼻子用的是 Dior。她習慣先上蜜粉，再用打亮補回光澤。
