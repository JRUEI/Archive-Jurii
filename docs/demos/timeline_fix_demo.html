時間軸線段「根本邏輯」解析與改善

您觀察得非常敏銳！把點改到 top-1/2 雖然解決了卡片內部比例，但破壞了跨卡片連線的數學邏輯。

❌ 為什麼「居中對齊 (top-1/2)」注定失敗？

如果圓點在卡片正中央，因為每張卡片高度不同（H1 ≠ H2），兩點之間的距離會變成 H1/2 + Gap + H2/2。

CSS 無法畫出一條預知下一張卡片高度的線，導致我們被迫讓 卡片A畫下半截、卡片B畫上半截，最後在中間相撞。
👉 結果：產生重疊色差、Hover 時線條斷成兩截。

✅ 終極解法：絕對定點 + 精確橋接

我們必須回到固定距離（例如 top: 32px），讓它剛好對齊右邊卡片的文字基準線。

只要起點固定為 32px，往下畫的線只要設定 bottom: -(Gap + 32px)，就絕對會精準命中下一張卡片的圓點中心！
👉 結果：每個區段只有「一條線」，完全無縫，Hover 效果完美連貫。
