內容管線

從節目音檔到靜態頁面

整條流程刻意設計成「人工把關、工具只做檢查」——沒有任何一支腳本會自動改寫既有內容。

  1. 01

    來源字幕

    從官方 YouTube 影片取得日文字幕，存為 content/ep0X.ja.vtt，原始檔永遠保留。

  2. 02

    翻譯與校正

    Whisper + LLM 產出雙語內容，再用詞語庫校正人名與專有名詞。

  3. 03

    三段式 Markdown

    寫入 content/episodes/epXX.md：frontmatter 加上三個固定章節。

  4. 04

    建置成靜態站

    gray-matter 解析後全頁預渲染，dynamicParams = false，執行期不再讀檔。

資料結構

一份 Markdown，三種閱讀深度

每個集數檔案的三個章節，直接對應網站上的三個閱讀模式。src/lib/markdown.ts 用正則切分章節， 把 ### [標籤] 標題 轉成卡片、把 [00:00:00] [說話者] 內容 轉成逐字稿列。

【精簡總結】

五行讀完一集

條列式重點。列表頁只取第一條當摘要，適合快速回顧「這集講了什麼」。

【無損還原】

分段落的完整內容

依單元切成帶標籤的卡片（開場／來信／單元／結語），保留引言區塊。這也是圖卡輸出的來源。

【完整逐字稿】

帶時間碼的全文

每列附時間與說話者，可對照原影片。目前全站共 7,741 列。

前端功能

網站實際做得到的事

  • 三種閱讀模式切換總結／無損還原／逐字稿，在 EpisodeViewer.tsx 以 state 切換。
  • IG 限動式卡片模式把無損還原內容排成 1080×1920 直式卡片，framer-motion 驅動，支援 40px 觸控滑動翻頁。
  • 整集圖卡打包下載html-to-image 逐張轉 PNG、JSZip 打包成 {集名}-Cards.zip，全在瀏覽器端完成。
  • 深色模式next-themes 控制，品牌紫／綠在明暗兩套各有一組色值。
  • 專注模式Header 設定面板可切換，狀態存在 localStorage（client-state.ts 用 useSyncExternalStore）。
  • 首頁版型切換列表／卡片兩種排列，同樣持久化在瀏覽器端。
  • 輕量首頁資料首頁只送出標題、日期、來賓與一行摘要；完整逐字稿不會進 client bundle。

工具鏈

指令與安全網

所有內容工具都是唯讀或 dry-run：只回報問題，不會替你改字幕或改 Markdown。

指令做什麼會寫檔嗎
npm run dev本機開發伺服器—
npm run validate:content檢查 frontmatter、章節、時間碼、說話者與詞語庫唯讀
npm run subtitles:check比對來源／候選 ASS：列數、時間碼、每行字數（超過 25 字失敗）唯讀
npm run glossary:dry-run只列出詞語庫「可能會替換」的位置唯讀
npm run verifylint → typecheck → build，部署前的完整驗證—
prebuildbuild 前自動跑內容驗證（Vercel 也會執行）唯讀

維護守則

寫給 AI 代理的邊界

AGENTS.md 針對高自主性模型定了四條硬規則，維護這個專案時必須遵守。

找不到就停下來

檔案或元件不存在時，禁止捏造替代內容；直接回報「找不到」，語氣保持中立客觀。

終端機指令要人批准

install／build／commit 一律只能提案。大規模重構要先送審查再動手。

內容與色系鎖定

既有集數 Markdown 覆寫前必須先讀再問。品牌紫／綠只能改 globals.css 的變數，元件內不得硬寫色碼。

展示一律用 HTML

規劃、比對、概念說明都要做成獨立的 demo HTML，不產出 Markdown 企劃書——這頁本身就是照這條規則做的。

部署

Vercel 設定

  • Node.js 24.x由 package.json 的 engines 鎖定，使用預設 npm run build，不需要 vercel.json。
  • 安全標頭next.config.ts 全站掛上 CSP（frame-ancestors 'none'）、Permissions-Policy、Referrer-Policy、nosniff、X-Frame-Options，並移除 X-Powered-By。
  • .vercelignore排除 demo HTML、報告、暫存字幕與封存腳本，公開站只留正式 Next.js 產物。
  • 錯誤頁error.tsx 不外洩 stack；未知集數走 not-found。
