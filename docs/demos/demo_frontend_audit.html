一、寫了但不會生效 dead styles

這四條是純粹的 bug：程式碼讀起來像有作用，實際上沒有。修掉不會改變任何你現在看得到的畫面，除了第 1 條會讓齒輪真的開始轉。

設定齒輪不會轉

壞掉

animate-spin-slow 在 Tailwind v4 需要 @theme 裡有對應的 --animate-spin-slow 與 keyframes。globals.css 兩者都沒有，所以這個 class 編不出任何 CSS——點開設定選單，齒輪是靜止的。

src/components/Header.tsx:116 · 對照 src/app/globals.css（全檔無 @keyframes）
改法　在 globals.css 的 @theme inline 補 --animate-spin-slow: spin 2.4s linear infinite;。

「精簡總結」的 Markdown 是裸的

壞掉

prose dark:prose-invert prose-brand 需要 @tailwindcss/typography，但它不在 package.json，globals.css 也沒有 @plugin 註冊。結果是 <ReactMarkdown> 吐出來的連結、粗體、斜體、巢狀清單完全沒有樣式——連結甚至不會變色或加底線。

src/components/TextMode.tsx:104（總結）· :123（全紀錄）
兩條路　(a) 裝 @tailwindcss/typography 並在 CSS 加 @plugin；(b) 這個站幾乎所有文字都是手動上 class，不如直接刪掉這三個失效 class，改在 ReactMarkdown 的 components 指定 a / strong 的樣式。(b) 較符合現況，也少一個相依。

404 的「返回首頁」按鈕 hover 沒反應

壞掉

bg-brand-brown 後面接 hover:bg-brand-brown——hover 色跟原色同一個，滑過去毫無變化。深色模式的 dark:bg-brand-tan 則根本沒有對應 hover。

src/app/not-found.tsx:14
改法　換成實際會變的色階，或照站上既有的實心強調寫法（SOLID_ACCENT）統一。

死碼

整支元件是孤兒。設定選單裡的「發光特效」開關本身是有用的（它驅動 TextMode 的段落聚焦），但 HeroGlow 這顆背景光暈從沒被掛上去。

四、鍵盤與報讀器 這節是我最建議先修的

全站 4,057 行裡 focus-visible 只出現 3 次，其中 2 次還是 hover 展開動畫的附帶效果。對只用鍵盤的人來說，現在有幾處是真的走不過去。

關起來的抽屜還在 Tab 順序裡

最該先修

逐字稿側邊抽屜關閉時只有 translate-x-full pointer-events-none。pointer-events-none 擋滑鼠，不擋鍵盤——裡面的搜尋框、兩個分頁鈕、上百句逐字稿全部還在焦點順序中。鍵盤使用者從頁面往下 Tab，會掉進一個看不見的面板裡出不來。

TranscriptMode.tsx:566–570
改法　加 inert={!isDrawerOpen}（React 19 原生支援）。一行，成本最低、影響最大的一條。

逐字稿每一句是 <div onClick>，不是按鈕

操作不到

點時間戳跳轉是逐字稿模式的核心操作，但它掛在 div 上配 cursor-pointer：鍵盤 Tab 不到、Enter 沒反應、報讀器不會說這是可點的。字幕群卡片與抽屜清單兩處都是。

TranscriptMode.tsx:437（字幕群）· :~795（抽屜清單）· 全站共 4 處 div onClick
改法　外層換成 <button type="button">，配 text-left w-full 保持現有版面，再補 aria-label="跳至 12:34"。

焦點框被關掉，沒有補回來

看不見

Header 設定鈕寫了 focus:outline-none 但沒有任何 ring；逐字稿搜尋框同樣 focus:outline-none，只換邊框顏色（zinc-200 → #A97C2B，兩者在白底上差異很弱）。鍵盤走到這兩個元件時，看不出焦點在哪。

Header.tsx:112 · TranscriptMode.tsx:667
改法　在 globals.css 的 @layer base 統一定一條 :focus-visible 的 ring（用 brand-ochre／深色用 brand-yellow），然後刪掉這兩處的 focus:outline-none。一次修完全站。

兩個 overlay 都不是正式的 dialog

語意

圖卡全螢幕已經做了 ESC 與 body 捲動鎖（做得不錯），但缺 role="dialog" / aria-modal、沒有 focus trap、關閉後焦點不會回到「放大」鈕。左右翻頁靠兩塊看不見的 <div class="w-1/4">，鍵盤完全操作不了。
抽屜則相反：有 ESC，但沒有捲動鎖——手機上滑動時背景會跟著滾。

CardMode.tsx:449,580,602,656 · TranscriptMode.tsx:263,566
改法　兩者都補 role="dialog" aria-modal="true"＋開啟時把焦點送進面板、關閉時還回觸發鈕；抽屜補上 CardMode 已經寫好的捲動鎖；全螢幕的左右鍵翻頁補 ArrowLeft/ArrowRight（ESC 的 handler 就在旁邊，順手）。

tab 語意做一半

半套

抽屜的分頁有 role="tablist"、role="tab"、aria-selected，但沒有 aria-controls、沒有 role="tabpanel"、沒有方向鍵切換。報讀器會宣告成「分頁」，使用者照 tab 的習慣按左右鍵卻沒反應——宣告了卻不履行，比不宣告更容易誤導。反過來，單集頁最主要的三分頁（精簡總結／段落紀錄／逐字稿）完全沒有 tab 語意。

TranscriptMode.tsx:576–610（半套）· EpisodeViewer.tsx:104–128（完全沒有）
兩條路　(a) 兩處都補完整（aria-controls + tabpanel + 方向鍵 + roving tabindex）；(b) 都退回單純的 <button aria-pressed>。(b) 更誠實也更省，因為這些分頁並沒有真正的 tabpanel 結構。

完全沒有 prefers-reduced-motion

前庭不適

全站約 100 處 transition／animate，零處尊重系統的「減少動態」設定。其中兩個是持續性動畫：字幕同步指示燈的 animate-ping（不停擴散）與 API 狀態點的 animate-pulse。加上 framer-motion 的進出場位移、hover:scale-105、段落聚焦的 scale-95 → scale-100。

TranscriptMode.tsx:403,484（持續動畫）· TextMode.tsx:28 · CardMode（framer-motion）
改法　globals.css 加一段全域 @media (prefers-reduced-motion:reduce) 收掉 transition/animation，framer-motion 另外用 useReducedMotion() 把位移改成純淡入。

五、版面細節 小，但會被碰到

建議的動工順序 三批，可以只做前兩批

第一批：外觀零變動 安全 · 建議直接做

做完之後截圖比對應該一個像素都不會變（唯一例外是齒輪開始轉）。但之後每一次改色、改層級都會輕鬆很多。

  • 修 AGENTS.md 的品牌色與專案名
  • 補 --animate-spin-slow；刪掉失效的 prose 三兄弟
  • #2E2118 → --color-brand-ink（12 處機械替換）
  • z-index 收成四層 token
  • harumatope- → jurii- 前綴
  • 決定 HeroGlow 掛回去還是刪掉 ← 這個需要你回答
不動任何品牌色相，符合 AGENTS.md §3。

第二批：鍵盤與輔助技術 視覺幾乎不變 · 效益最大

除了新增的焦點框（只在鍵盤操作時出現，滑鼠使用者看不到），其他都是行為修正。

  • 抽屜加 inert（一行，最划算）
  • 全站統一 :focus-visible ring，移除兩處 focus:outline-none
  • 逐字稿的 div onClick → <button>
  • 兩個 overlay 補 dialog 語意＋焦點歸位；抽屜補捲動鎖；全螢幕補方向鍵
  • tab 語意收斂（建議退回 aria-pressed）
  • 全域 prefers-reduced-motion
不動色彩，不動版面。

第三批：對比與版面 會改變外觀 · 需要你逐條點頭

這批看得出差別，所以照 AGENTS.md §2 的人工審核點，我會等你確認再動。

  • text-zinc-400 → zinc-500（次要文字，差異很小但過 AA）
  • 月曆無直播日、「尚未整理摘要」說明文字提亮
  • 拿掉 #d8b4fe，三個紫調深色底收斂到 zinc 系
  • 匯出卡頁尾 #aaa 在亮色主題下加深 ← 分享出去的圖，我建議優先
  • 亮色 brand-yellow 在小字膠囊上換成 brand-ochre（4.95，過 AA；色相不變，只是深一階）
  • scroll-mt 統一並計入手機 SNS bar
  • 觸控目標用 ::before 擴大（視覺不變）
  • 中文小字地板拉到 13px
這批唯一碰到品牌色的是最後一項：brand-yellow → brand-ochre。兩個都是現有色票裡的顏色，不新增色相，但視覺上會深一點——這條特別需要你點頭。

已經做對的，不要動 免得下次有人「順手優化」掉

  • 卡片高度寫死、目錄與簡述在同框換面——換集數時框不跳。這是刻意的，不是沒做 responsive。
  • mono 標籤與中文標題走 items-baseline 而非 items-center——兩者行高不同，置中會錯位。註解已經寫明原因。
  • 月曆一律補滿 6 週、格子壓成 aspect-[16/15]——正方形視覺上會偏高，壓 6% 才像方的。這是真的懂排版的人才會做的調整。
  • text-wrap-style: pretty ＋ 標題 balance——中文每字可斷行，這兩條直接解掉「最後一行只剩一個字」。
  • useHydrated() 的 SSR 一律回預設值——localStorage 偏好不會造成 hydration 不一致。這個坑很多人踩。
  • 全站 tabular-nums＋ mono 處理日期與時長——數字對齊得很乾淨。
  • 圖卡匯出用 inline style——html-to-image 讀不到 Tailwind class，這是必要的取捨。要修的只是它那份色表該跟 token 同源，不是改寫法。
