# 逢田珠里依 SHOWROOM 2026/09/03

## 【精簡總結】

* 開場她被禮物洗版，一路喊了幾十次「STOP」還是攔不住，最後說「我腦袋現在完全沒在運作」，改用投票模式。
* 投票數字設成 10，因為距離寫真集發售剛好十天——而她是看到粉絲做的倒數影片，才發現那也是距離生日十天。
* 她說實體書自己還沒看到，成員也還沒看到。20 歲的最後一天要工作，「能跟成員在一起真好」。
* 酒的話題佔了很長一段。她說自己大概喝得了但不會喝，理由是「我是膽小鬼」——聽說喝了會變得不像自己，「當偶像的話這很可怕」。但她非常想看大家喝醉的樣子，甚至說要 LINK 快點開放傳照片和影片。
* 她昨天自己剪了瀏海，剪出大事。順帶爆料她偶爾會幫山田杏佳剪瀏海，還開玩笑要杏佳在演唱會前的貼文上 tag 她，「因為杏佳的瀏海也是我剪的嘛」。
* 她說自己是「全日本最不適合齊瀏海的人」，也沒有要留長的打算；額頭要露的話一定得配放下來的頭髮。
* 雙馬尾跳舞的災難現場被她演了一遍：轉圈時頭髮甩過來黏在唇釉上，她一邊擦眼淚的編舞、一邊撥頭髮，心裡喊「走開走開別過來」。
* 她公布了一個「這輩子大概不會做」的髮型：頭頂高度的雙丸子頭。化妝師也認同「珠里依可能不是走那個路線的」。她說自己希望頭髮是會晃動的。
* LINK 的反向提問她全部看完了，包括有人在開演前三分鐘傳來的。她說最有趣的是「什麼時候知道、什麼時候喜歡上」的答案分佈，也意外知道了不少人的感情狀況。
* 香水她說是 Maison Margiela 的某一款，但完全想不起是哪一支，只記得盒子上有紫色，承諾隔天一定在 LINK 上公布。
* 後半是完整的 Tower 排行榜點名，二十位一位一位念完，中途穿插石川、大宮、生誕祭與各種約定。

## 【無損還原】

### [開場] 攔不住的禮物

開場沒多久就被禮物淹沒，連喊了幾十次 STOP，一邊道謝一邊說怎麼送這麼多。因為是上班時段，她改切成投票模式。
* **一路喊停**：她開場沒多久就被禮物淹沒，連續喊了幾十次「STOP」「等一下」，一邊道謝一邊說「為什麼要送這麼多啦」。她坦言「我現在腦袋真的完全沒在運作」。
* **改用投票**：她說因為開播時間剛好是大家還在上班的時段，所以要切成投票模式。
* **久違**：她說「直播變得有點久違了」。

### [髮型] 昨天的雙馬尾與被剪壞的瀏海

昨天綁雙馬尾是問過大家的結果。她說很想放下來但太熱受不了，昨天自己剪瀏海剪出大事，還招認山田杏佳的瀏海也是她拿普通剪刀剪的。
* **昨天的雙馬尾**：她說昨天綁了雙馬尾。起因是她在 LINK 上問大家「髮型弄什麼好」，收到很多回應；另外她跟天野香乃愛已經決定要用夏日雙馬尾的髮飾，所以是既定路線。
* **想放下來但辦不到**：她說自己其實非常想把頭髮放下來，「真的真的很想放下來，可是太熱了做不到，眼淚都要流出來」，因為她很會流汗。巡演首日她放下頭髮，「到第三場左右已經快被汗淹死了」。
* **自己剪瀏海**：她說瀏海長長了，昨天隨便自己剪了一下，「結果出大事」。她說自己不擅長瀏海，「現在也很亂，破破爛爛的」。
* **她也幫別人剪**：她說有個好笑的事——她偶爾會幫山田杏佳剪瀏海。她說偶像常常會在貼文裡 tag 美髮沙龍或美睫店，「所以我一直在演那個梗，說『演唱會前被弄得很可愛』然後在照片這邊 tag 我嘛，因為杏佳的瀏海也是我剪的啊」。她說用的就是普通的剪刀，「現在要是被美髮師看到大概會發抖」，還說偶爾會憧憬地學專業的手勢比劃一下。
* **她的瀏海設定**：她說自己的瀏海基本上是偏長的設定，每次跟成員說「剪太多了」拿給對方看，都會被回「明明還很長啊」，因為有些成員是齊瀏海、幾乎不燙、剪在眉毛正上方。她自己是蓬鬆地捲一下、落在眉毛下面，「比大家都長」。她說剛剪完所以現在算短的，日常剛剛好，但要演唱會的話還是偏長。
* **齊瀏海**：她說「沒有要剪齊瀏海的預定，我是全日本最不適合的」，還說會顯胖。有人講「偶像瀏海」，她說「與其說想要偶像瀏海，是因為齊瀏海不適合我」。
* **不會留長**：她說瀏海不會留長。有人問「留長是指變成沒有瀏海嗎」，她提到像結香那樣的，然後說「不是啦，我臉太小了，這樣往上撥也只有這麼一點點，臉。結香的臉才是真的小」。
* **額頭**：她說瀏海可以擋額頭，但流汗就會跑出來。她說巡演的某一場也許會露額頭，「不過我頭髮不放下來的話就不想露額頭」。

### [髮型] 跳舞時的頭髮攻防

她說雙馬尾很難跳，一轉圈頭髮就甩過來，還會黏在有光澤的唇釉上，變成一邊做擦眼淚的動作一邊撥頭髮。馬尾和半丸子也各有麻煩。
* **想做上盤但不敢**：她說其實也想做往上盤的造型，可是新生的髮際線那一帶比較空，全部往上就會全開，「有點害羞」。她說天氣熱想全部盤起來，可是盤起來脖子附近又太空，「所以要留一點下來，很難吧，這很麻煩的」，並抱怨這樣一來「髮型會越來越少」。她補一句「馬尾從正面看也什麼都沒有嘛」。
* **雙馬尾很難跳**：她說自己最順的髮型才最好跳，雙馬尾「真的很難跳」，因為太少做，一轉圈頭髮就甩過來。她現場重演了一次動作，說轉的時候會「嗚」一下，一邊跳一邊在心裡喊「走開走開，別過來」，「一邊轉一邊覺得好礙事」。
* **黏在嘴上**：她說自己喜歡有光澤的唇釉，所以那邊的頭髮會直接黏上來。當時那首歌的編舞剛好是擦眼淚的動作，她就變成「一邊做擦眼淚的動作、一邊把頭髮撥開地跳」。她說「真的很討厭，很難回到原位」，所以「平常就綁雙馬尾跳舞的人真的很厲害，駕馭得很好」。
* **馬尾與半丸子**：她說馬尾也有馬尾的問題，會有一整束打過來。她也提到反過來，平常都綁雙馬尾的成員會覺得放下來很難跳。她本來以為半丸子最輕鬆，但在 K Arena 那次跳起來的時候超困擾，「幾乎跳不起來」，還會「啪」地一下彈到。

### [髮型] 這輩子大概不會做的那個

她出題問哪個髮型自己這輩子不會做，答案是頭頂的丸子頭和雙丸子，說不適合的未來看得見，化妝師也同意。她只希望頭髮是會晃動的。
* **出題**：她說有一個髮型她這輩子大概一次都不會做，「猜得到嗎」，並說常跟化妝師聊這個。
* **提示與否認**：她說有正式名稱、不是長度問題。有人猜「波堤獅頭」，她說很多人說喜歡，「目前沒有預定，不過也沒有發誓不做」；她說水母頭她做過。
* **答案**：頭頂那個高度的丸子頭、雙丸子。她說「不適合的未來真的看得見」，還說「這在日本偶像界我大概是最不適合的」，觀眾安慰她她只回「不，真的有這種事，救命」。相較之下「波堤獅頭對我來說比雙丸子安全」。
* **化妝師也同意**：她說跟化妝師講的時候，對方說「的確，珠里依可能不是走那個路線的」，她回「就是說啊」。
* **她的偏好**：她說「我希望頭髮是會晃動的」。她補充影像作品的時候會放下來，演唱會就得綁起來，「因為很會流汗，不然很辛苦」。

### [LINK] 反向提問的收穫

她說 LINK 的回覆全部都看過了，開演前三分鐘還在讀。最有趣的是大家什麼時候知道她、什麼時候喜歡上她，也知道了不少人的感情狀況。
* **票數分佈**：她說 LINK 上馬尾派可能最多，另外因為夏日祭典而喜歡上她的人偏好雙馬尾，所以她「借了大家的勇氣綁了雙馬尾」。也有人喜歡直髮、喜歡捲了放下來的。
* **她全部看完了**：她強調自己真的有看，「全部都過目了」，甚至提到「昨天演唱會開演前大概三分鐘的時候有人傳來，我還在看」。
* **最有趣的部分**：她說最有趣的是「什麼時候知道我、什麼時候喜歡上我」的回答——有人是知道跟喜歡同時發生，也有人很久以前就知道、甚至去過演唱會，但當時沒有特別入坑，隔了一段時間最近才喜歡上、現在常常來看。
* **意外的收穫**：她說也知道了不少人的感情狀況，「還有人是『欸你結婚了喔』」。她說看到有人寫「還是最喜歡珠里依」很開心，也有人說「想讓珠里依當戀人」。

### [不喝酒] 「我是膽小鬼」

她說自己大概喝得了但不會喝，理由是膽小——聽說喝了會變得不像自己。反過來很想看大家喝醉的樣子，催 LINK 快點開放傳影片。
* **她的立場**：她說自己大概喝得了，但不會喝。理由她想了一下，說「因為我是膽小鬼」——聽說喝了會變得不像自己，「那不是很可怕嗎，當偶像的話」。她補一句「所以不是偶像之後說不定會喝」。
* **她真正想要的**：她說「所以我才想看大家喝酒的樣子」。她說得很堅持——「因為那是我絕對看不到的樣子」，還說想看大家睡著的樣子、吃飯的樣子。她一連串追問「會怎樣？會變得話多嗎？會想睡嗎？會哭嗎？聲音會變大嗎？」
* **要 LINK 加功能**：她說「果然得快點讓 LINK 能傳照片和影片才行」「我要看大家喝醉的影片」。
* **她的假設**：她說如果自己開始喝酒、喝醉了、在 LINK 上傳語音給大家，「那不是很可怕嗎」，「半夜三點傳個『喂——』過來，可怕可怕可怕，我不要」，最後結論「所以我不喝，絕對不喝」。
* **家裡的酒**：她說自己周遭幾乎沒看過有人喝，「會喝的大概只有我媽跟我姊，我爸不喝」。她提到莉子，也提到怜音那邊是「媽媽不能喝、姊姊很能喝」，還說「不過媽媽超愛啤酒的」。

### [倒數] 距離發售與生日各剩十天

投票數字設成 10，是因為離寫真集發售剩十天；粉絲做的倒數影片才讓她發現離生日也剩十天。做成書的樣子她自己還沒看過。
* **投票數字**：她說投票數字設成 10，是因為「距離寫真集發售還有十天」。
* **粉絲提醒的事**：她說有人做了倒數影片、在裡面寫了，她才發現「距離生日也剩十天」。她連說「一轉眼就到了」「明明前陣子才在拍攝」「明明前陣子才跟大家發表」。
* **還沒看到實體**：她說做成書的樣子自己還沒看過，很期待；成員也還沒看到。
* **20 歲的最後一天**：她說 20 歲最後一天要工作，「能跟成員在一起真好」。她說自己從沒特別留下什麼，「也沒有因為是 20 歲就特地做什麼」。

### [美妝] 打亮、蜜粉與想不起來的香水

她說臉上的光澤來自疊在腮紅上的粉紅打亮，鼻子用 Dior。香水是 Maison Margiela，但她想不起來是哪一支，只記得盒子上好像有紫色。
* **打亮**：她說臉看起來很有光澤，是因為某牌粉紅色那款打亮，「我真的超喜歡，總是疊在腮紅上面」；鼻子則是用 Dior 的打亮。
* **順序**：她說自己會先上蜜粉，再用打亮補回光澤，「我是那種人」。
* **香水**：她說是 Maison Margiela 的，但「不知道自己在用哪一支」。她說買的當時是「最近剛出」的新品，現在已經用完了，確定不是 Lazy Sunday Morning。她說自己只有買的時候看過名字，「看片假名也認不出來」，只記得「包裝、買來的盒子上好像有紫色」。她說會晚點貼到 LINK 上，「如果十二點前來得及就貼，不過大概是明天了」。
* **她的補充**：她說有一款被形容成「像 Mira 的收藏」的，「那支相當甜，不要嚇到」。她也說自己從以前就很喜歡被別人跟她用一樣的東西，「不用在意，我很開心」。

### [巡演] 石川、大宮與落選的人

第一次去石川，髮型還沒決定。她惦記著這次沒抽中的人，說哪怕只有一場能見到就很開心，也謝謝平日場鼓起勇氣來的人。
* **石川**：她說第一次去石川縣，還沒決定要弄什麼髮型，並多次說「後天見」。
* **落選**：她說很多人告訴她這次沒抽中，她問「怎麼樣呢」「見得到嗎」，並說「哪怕只有一個場次能見到就很開心了」。
* **平日場**：她說大家都很忙，昨天又是平日，「平日大家反而是鼓起勇氣來的吧，謝謝你們」。

### [感謝] Tower 排行榜點名

她把二十一位的順序先念過一次確認，再一位一位叫名字回應留言，聊到髮型、生日、大宮的立牌，還跟人立下好好吃青菜的約定。
* **點名方式**：她先把順序整個念一次確認，然後一位一位叫名字、回應對方的留言。順序是：ふかちゃん、通りすがりの、つっち、ゆ平君、ことみちゃん、カシーナさん、レイナちゃん、たきソウルさん、七なみちゃん、あやとTさん、えんさん、きへさん、ガッくん、くるちゃん、りもち、ひろかちゃん、待機と申します、こしさん、ささみちゃん、ぽちゃん、まさ君。
* **其中的片段**：她跟 ふかちゃん 說「以後每年都這樣聊吧」；對 通りすがりの 說「我的手勢有傳達到吧」，並比了一次「路過」的動作；跟 つっち 說「等能再辦發布會活動的時候會來嗎，為了辦發布會活動，我要努力讓單曲發得出來」；祝 ゆ平君 9 月 2 日生日快樂，說「一起開幕吧」；跟 ことみちゃん 討論髮型，說「想看的話就高馬尾吧」，又補「抱歉，這不是我要弄的意思」；跟 レイナちゃん 為首日滿身汗道歉，「居然還沒討厭我」；跟 七なみちゃん 說「再六天就能講話了」；對 あやとTさん 抱怨生誕祭每年都太短，「應該要再長三倍才對」；跟 きへさん 聊大宮和立牌，「立牌很佔位置沒關係嗎」；跟 ガッくん 說「≒JOY 的夏天連折返點都還沒到」，得知對方是「20 歲最後一場演唱會」時笑說「我不知道呢，嚇一跳，我會加油」；跟 くるちゃん 說「我覺得我們已經很要好了」；跟 ひろかちゃん 說「我看到你了，你在走道邊、在角落對吧」；跟 待機と申します 確認昨天有打招呼、「一定要再對到眼」；跟 こしさん 立下「好好吃青菜」的約定，笑說「我自己是破戒了，不過我會偷偷盯著你」；跟 ぽちゃん 說「照片挑可愛的給我，我大概都閉著眼睛或做鬼臉，拜託了」。
* **最後一位**：まさ君 排在最後，她說「抱歉拖到最後一刻」。她也提到看到有人寫了「I love you 什麼的」，說「那是什麼意思呢，要好好告訴我喔，請用很大很大的聲音」。

### [收尾] 香水的承諾與晚安
