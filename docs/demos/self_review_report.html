自我審理報告：遺漏與瑕疵清單

感謝您的提醒，我仔細盤點了最近的實作，確實發現了幾個隱藏的體驗瑕疵！

1

HTML Demo 的導覽列忘了對齊

您之前特別交代「影片清單、首頁跟設定，這個上下的 length 記得調成一致的」。我在 React 正式版中確實將它們統一改成了 h-10 (40px) 的固定高度，但我竟然忘記同步更新給您看的 HTML Demo (`timeline_demo.html`)！ 導致您在看 Demo 時依然覺得高低不平。

✓ 修復方案：已全面將 HTML Demo 的 Header 按鈕也套用嚴格的 40px 高度對齊。
2

時間軸間距重複計算 (破圖邊緣)

在 React 程式碼中，我為了拉開卡片距離，同時保留了外層的 gap-8 以及卡片容器的 pb-12，這導致兩集之間的距離被「重複疊加」變得過大 (高達 80px)！更嚴重的是，這導致我計算時間軸垂直線段時產生了 8px 的超界重疊 (Overlap)，放大看會發現線段接縫處怪怪的。

✓ 修復方案：移除多餘的 pb-12，完美利用 gap-8 作為精準間距，並將連接線長度修正為精確跨越 gap 的長度。
3

關閉「特效」時，最新一集的邏輯不一致

目前如果從設定選單把「特效」關閉，最新一集的時間軸圓點會變成「死氣沉沉的灰色」，但下方延伸出去的線條卻還是「紫色的漸層」。更糟的是，我們才剛把最新一集的小標改為「亮綠色」，圓點跟線條卻沒跟著變成綠色，導致視覺重點非常混亂。

✓ 修復方案：統一將最新一集的圓點與漸層線預設改為「亮綠色 (Brand Green)」，即使關閉特效，它依然會是顯眼的綠色實心點，完美呼應旁邊綠色的最新回小標！

我正在同步把這些細節進行全網 (HTML + React) 的深度修正！
