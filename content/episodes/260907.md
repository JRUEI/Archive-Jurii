# 逢田珠里依 SHOWROOM 2026/09/07

## 【精簡總結】

* 這天是《週刊 PLAYBOY》的發售日，她開場先謝已經入手的人，然後花了一分多鐘跟開燈、開冷氣、一支沒電的遙控器奮鬥。
* 她看完了粉絲交的「畫珠里依」挑戰，說畫得好的大概只有 7%，但「人會喜歡上跟自己像的人」，所以那也沒錯。最麻煩的是有人把奇怪的細節重現得超精準，「那不是畫得差，是畫得太好了」。
* 她想找自己以前畫的自畫像，跑去翻家裡的儲藏室，翻不到，倒是差點把泰國褲拍進鏡頭。
* 生日 TOWER 的回禮問題佔了整整八分鐘。她問前輩怎麼做、問成員怎麼做（大西葵是後續補一場直播），最後決定「改天開一場直播，把送禮的人名字一位一位念出來」。她反覆強調「有這份心意我就很開心」，還說與其送她，不如拿去吃點好吃的。
* 她講漏了 LINK 的 Letter 有搜尋功能，可以回頭找誰傳過什麼，講完馬上緊張地說「這絕對不可以剪成片段」。
* 後半是連環「神迴避」故事：國中在社團前用手機查洋蔥切法被顧問抓到，她當場改口說在查色紙設計；國一在車站看 LINE 漫畫被老師攔下，她假裝在看媽媽傳的路線圖，本來要沒收一個月的手機隔天就還她了。
* 最精彩的是她媽媽的版本：便服跟化妝包誤放在講桌上被沒收、被隔離在教職員室隔壁，她趁老師查名冊的空檔從教室小窗鑽出去，用口袋裡的十圓硬幣打公共電話給姊姊串供，再鑽回去裝乖——學校的電話一分鐘後才打到。
* 她順便宣布寫真集同日還有多收錄 20 頁其他鏡頭的數位版，並認真地說「LINE 漫畫上看不到」。
* 收尾談 9/13 生日當天的心情：比起期待，忐忑更多，怕大家「燃燒殆盡」不再來；她說「跟大家在一起的時候是最真實的自己」。
* 十二點一到她說「我是灰姑娘」就道晚安，結果發現直播根本沒斷，慌張地補了一句「好險，我通常會開始唱歌的」。

## 【無損還原】

### [開場] 發售日與打不開的遙控器

連兩天直播，開場先謝過入手《週刊 PLAYBOY》的人。中途說有點熱要開冷氣，卻跟一支久沒用的遙控器纏鬥了一分多鐘。
* **兩天連播**：她開場說「連續兩天直播喔」，並說自己還在家裡。
* **今天是發售日**：她說今天是《週刊 PLAYBOY》的發售日，向已經入手的人道謝。
* **燈跟冷氣**：她中途去開燈，說「有點熱，我開冷氣」，然後跟一支「最近完全沒在用」的遙控器纏鬥了一分多鐘，懷疑是電池沒電，最後還是開起來了。

### [投稿] 畫像挑戰的 7%

她說粉絲自畫像挑戰裡畫得好的只佔七趴，有人把奇怪的細節重現得太精準。截圖已經收不回去，還有人拿那些畫當 LINK 頭像。
* **命中率**：她說粉絲交上來的自畫像挑戰裡，畫得好的「大概只佔 7% 左右」。
* **她的解讀**：她說常有人說「人會喜歡上跟自己像的人」，所以她覺得那句話大概沒錯，「說自己有自信的那幾位，說不定就是那個數字裡的人」。
* **重現得太精準**：她說有些人會把奇怪的細節重現得超精準，「那不是畫得差，反而是畫得太好了」，還提醒「不可以看太仔細喔」。
* **截圖收不回去**：她說自己截了不少圖，「已經收不回去了喔」。
* **頭像換掉了**：她說最不好意思的是很多人把 LINK 頭像換成了那些畫，害她找不到原本的樣子。

### [家裡] 找不到的自畫像

想翻出以前畫的自畫像和老師畫的那張，離開鏡頭找了半天沒找到，說那間房現在當儲藏室。回來還緊張確認泰國褲有沒有入鏡。
* **想翻出舊作**：她說想找自己以前畫的自畫像，還有老師幫她畫的那張，於是離開鏡頭去翻。
* **翻不到**：她翻了半天說「找不到」，回來時說那邊本來是爸爸的房間、現在當儲藏室，所以不知道收到哪去了。
* **差點入鏡**：她中途緊張地確認「我的泰國褲剛剛是不是入鏡了」「差一點，剛剛真的拍到了，好險」。

### [生日] TOWER 的回禮該怎麼辦

生日收到的 TOWER 每年都來不及回禮，她問了前輩和成員的做法，最後決定另找一場直播一位一位念名字，還一直說有心意就夠了。
* **開場的顧慮**：她說生日那天每年大家都會送很多 TOWER，「真的很感謝，可是我每年都沒能好好回禮」，所以想跟大家商量今年怎麼做。
* **問前輩**：她問「前輩們都是怎麼做的」，聽到有人已經不念 TOWER 了，她說「已經到那種次元了嗎」。
* **問成員**：她問 ≒JOY 的成員今年怎麼處理，提到大西葵「看起來很辛苦」，而且葵是「後續補一場直播」。
* **當下念不行**：她說收到的當下就念的話，「我覺得自己會處理得不夠好」。
* **她的大前提**：她重複強調「有這份心意我就很開心了」，說自己希望大家盡量不要花錢，還自己補一句「我說這種話會不會被罵啊」。
* **投票也不妥**：她說想過改成投票功能，但「只用投票功能好像對其他方面也很失禮」。
* **她想要的東西**：她說用 Letter 傳「生日快樂」她很開心，「因為我會一看再看」；還提議傳「喜歡我哪裡」「跟我見面時的回憶」，還沒見過面的人就寫想一起做什麼。她說「希望你們告訴我一百個喜歡我的地方，我很不安啊」。
* **結論**：她想起去年好像也是只念名字，最後決定「今年就改成後續找一場直播只念名字」，並反覆確認「真的可以嗎」。她說會把送 TOWER 的人名字準備好，一位一位念。
* **反過來的話**：她說「你們才比較像偶像吧」，又說「大家都已經買了寫真集了」，如果現在有人想送 TOWER，「請你們拿去吃點好吃的」。

### [LINK] 不能剪的那段功能說明

說 Letter 的訊息會留著、還能搜尋關鍵字，講到一半自己緊急煞車，反覆叮嚀這段絕對不能剪成片段放上網。
* **Letter 會留著**：她說 Letter 有點像 LINE，訊息會留著，她有時候會回去看某個人傳過什麼。
* **可以搜尋**：她說自己搜尋「生日」，就能把大家傳來跟生日有關的訊息都翻出來，講到一半自己遲疑「這個可以講嗎」，又說「超劃時代的」。
* **緊急煞車**：她講完立刻慌張地說「這個絕對不可以剪成片段」「其他人絕對絕對不可以放到 Twitter 上」，理由是「我也不想被叫去約談，收到聯絡我會怕」，還笑說「我要是在時間軸上看到，我會對那個人做點什麼的」，最後總結「直播就是這點可怕」。

### [日常] 看不懂地圖，也開不了寶特瓶

最近的煩惱是看不懂 Google 地圖，還有打不開寶特瓶。去看乃木坂那天在月台和電車上奮鬥二十分鐘，開了條縫水噴得滿身。
* **地圖**：她說最近的煩惱是看不懂地圖——「地圖」App 她看得懂，但 Google 地圖看不懂，講完又自己接「我講這個大概又要被罵了」。
* **寶特瓶**：她說最近連寶特瓶都打不開，現場示範還是轉不開，手上還留著繭。她強調「我握力超強的」，但「一直以來意外地都是成員幫我開的」。
* **乃木坂那天**：她說有一次去看乃木坂演唱會的路上完全打不開，在月台努力好幾分鐘、上了電車還在努力，渴到「快昏倒」。周圍都是穿戴乃木坂周邊的人，她想過用「我不是可疑人士」的路線求助，正猶豫時瓶蓋開了。
* **總共二十分鐘**：她說前後總共花了大概二十分鐘，而且只開了一點點就卡住，水噴得到處都是，她從那個縫硬擠出來喝，衣服全濕。對座那位同樣穿著周邊的人一直跟她對到眼，「因為我那樣子實在太奇怪了」。
* **下次的辦法**：她說下次再開不了，就在 LINK 上公告「我現在在某某站，誰來幫我開個寶特瓶」。

### [神迴避] 洋蔥的切法

排球社聚會挖出的往事：她被顧問老師抓到用手機，畫面上查的是洋蔥切法，臨場改口說做色紙卡住了，老師還說要幫她查。
* **緣起**：她說前陣子排球社聚會，聊起以前的事，就冒出很多「原來珠里依當年神迴避過超多次」的故事。
* **超嚴的校規**：她說學校的手機是一到校就被收走的，連帶進校門都要申請，「可以帶但不能用」。
* **被抓包**：她說社團活動前，大家圍成一圈用她的手機查東西，顧問老師一走過來，大家「唰」地散開，被問「你們怎麼了」。而她當時查的是——洋蔥的切法。「為什麼要查啊？我也搞不懂，我自己完全不記得。」
* **臨場改口**：那陣子接近畢業季，旁邊剛好有孩子拿著色紙，她就改口說「我在做色紙，做到卡住了，只有這一下下讓我查一下，真的非常抱歉」。
* **老師的回應**：老師說「這種事你跟我說，我幫你查就好了」，她一邊心裡道歉一邊回「好的，那就麻煩您了」。她說「現在想想真的對不起」「老師對不起」。

### [神迴避] 媽媽從小窗鑽出去那次

媽媽把便服化妝品忘在講桌被沒收，謊稱拿錯姊姊的包包，趁學校查號碼時從小窗鑽出去打公共電話串供，一分鐘後姊姊完美接球。
* **前提**：她說這種故事還有三件左右，但媽媽的版本才是「全世界最好笑的」。媽媽已經睡了，所以由她轉述，並先聲明「真的是我媽講比較好笑」。
* **第一個大蠢蛋**：媽媽的學校也超嚴。她放學後要去玩，把便服跟化妝品全帶去學校，結果一到校就把那包東西誤放在講桌上。她評「光是這點就夠蠢了，第一，大蠢蛋」。
* **裝傻**：女老師問「這是誰的」，媽媽承認後被沒收，卻立刻改口「我跟姊姊的包包拿錯了」「這不是我的」。
* **被隔離**：老師說要確認，把她關在一個房間，那房間前面就是教職員室，並說要打電話給家長。
* **十圓硬幣**：媽媽算準學校要翻名冊查號碼有空檔，發現口袋裡有兩枚十圓硬幣，從教室下方的小窗鑽出去，全速衝到地下的公共電話。
* **一分鐘的串供**：她打給姊姊，不給對方開口的機會：「等一下學校會打電話來，在人家問你之前就說『我妹妹拿錯了我的包包』」，講完掛斷、跑回去、再從小窗鑽回原位裝乖。學校的電話大概一分鐘後才打過去。
* **姊姊也很強**：電話一接通，姊姊就先說「不好意思，是我妹妹包包的事嗎？好像是妹妹拿錯了我的那份」。珠里依評「這故事很恐怖吧，那孩子明明應該被關著的」。
* **後話**：她說媽媽跑很慢，「只有那次快得不得了」；還說媽媽那是千金學校，不是在混，「硬要說是那種很講究禮儀的學校」。要是那次沒迴避成功，升學會出問題，媽媽自己說「真的好險」。她補一句「那個小窗超有意義的，不知道會怎麼改變人生嘛」。

### [宣傳] 差點忘記的數位版

講到一半驚覺還沒宣傳數位版，連道好幾次歉，說寫真集同日推出多二十頁其他鏡頭的版本，還強調那在 LINE 漫畫看不到。
* **突然想起**：她講到一半驚呼「糟了，我還沒宣傳數位版」，連道了好幾次歉，還說「耳朵都要被震掉了」。
* **內容**：她說寫真集發售同一天，也確定推出追加了二十頁其他鏡頭的數位版。
* **她的補充**：她認真地說「這在 LINE 漫畫是看不到的喔」「分享給兩個人也看不到喔」。

### [神迴避] LINE 漫畫與車站的老師

通學路上滑 LINE 漫畫被別校老師拍肩抓包，她假裝翻包包切到媽媽傳的路線圖，說自己在看集合門的位置，隔天手機就還她了。
* **通學路線**：她說自己一直跟同一個人一起上下學，而學校規定上下學也不能碰手機，「連電源都不能開」，不過「算是心照不宣，只是被抓到就完蛋」。
* **每天一話**：她說自己超愛 LINE 漫畫，跟同社團的那位每天互相推薦、一起追進度，因為那個機制每天只能往下看一話。
* **被拍肩**：去打練習賽那天，一到最近的車站就有人拍她肩膀：「你是某某學校的學生對吧」「我是那所高中的某某老師」「你剛剛在滑手機對吧」。同行的孩子當場石化，「一副世界末日的表情」。
* **一個月的代價**：她說學校規定滑手機被抓到要沒收手機一個月，同班就真的有人被收滿一個月。
* **臨場改口（二）**：那天對方學校在辦歸國子女入學考，集合的門跟平常不同；她媽剛好用 LINE 傳了路線圖給她。她一邊假裝在包包裡翻手機，一邊切到 LINE 畫面，說「今天有入學考，集合的門跟平常不一樣，我不知道路，所以在看這張地圖」。
* **結果**：老師說「啊，這樣啊」，「總之先沒收一下」——結果本來一個月的期限，隔天就還她了。她邊笑邊說「真的對不起，太惡劣了」「就當成國一的死小孩，原諒我」。
* **自我辯護**：她強調「我真的不是不良少女，只是一個想滑手機、想看 LINE 漫畫、想查洋蔥切法的學生而已」，還說自己幾乎沒有繞過路（繞路也是絕對禁止的），頂多是看完乃木坂演唱會吃個東西才回家，「換掉制服就 OK，穿制服在外面晃才不行」。

### [黑歷史] 一次分享給六個人的復仇漫畫

手滑觸發分享機制，把封面很兇狠的復仇系漫畫一次分享給六個人還收不回來。她說國中跟社團同伴每天追一話，現在偶爾還在看。
* **她的口味**：她說國中很愛看「爽快解氣」的復仇系漫畫，「那種作品的封面縮圖通常都蠻兇狠的」。
* **手滑**：她說前陣子滑 LINE 動態時手一滑，觸發了「分享給兩個人就能多看一話」的機制，結果把那部超兇的復仇系作品一口氣分享給了六個人，變成「珠里依分享了這個」的通知。
* **丟臉的點**：她說那些人都知道她現在在做什麼，「一定會想『這孩子在看什麼啊』」，而且收不回來。她說被發出去的大概不是《女神降臨》就是復仇系的。
* **每天一話的青春**：她說《女神降臨》她跟社團同伴每天追，因為要滿二十四小時才能看下一話，早起的人會被說「你今天很早喔」。她把作品形容成「用化妝變成女神」，自己吐槽「這說明也太隨便了」。
