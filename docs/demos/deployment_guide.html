網站預覽與上線指南

從本地手機預覽，到正式發布至全球網路的完整流程與方案比較。

階段一：用自己的手機預覽 (免上線)

只要電腦和手機連著同一個 Wi-Fi 就能直接觀看測試！

  1. 確保處於同一個網路

    請確認您的手機與目前這台電腦，連接著同一個 Wi-Fi 網路。

  2. 查詢電腦的內部 IP 位址

    # 在 Windows 的命令提示字元 (cmd) 或 PowerShell 輸入：

    ipconfig

    在結果中找到「IPv4 位址」，看起來會像 192.168.1.X。

  3. 在手機瀏覽器輸入網址

    拿起手機，輸入剛才查到的 IP，後面加上 3000 通訊埠：

    http://192.168.1.X:3000

如何使用 Vercel 上線？ (最推薦流程)

  1. 將程式碼上傳到 GitHub： 這是第一步。在 VSCode 中將目前的所有變更 Commit，並發布 (Publish) 到您的 GitHub 帳號，建立一個私有或公開的儲存庫 (Repository)。
  2. 註冊/登入 Vercel： 前往 Vercel.com，選擇「Continue with GitHub」直接用 GitHub 帳號綁定註冊。
  3. 匯入專案： 登入後，在 Dashboard 點擊 「Add New...」 > 「Project」。Vercel 會列出您 GitHub 上的專案，找到您的 Wiki 專案並點擊 「Import」。
  4. 一鍵部署： 完全不需要修改任何設定，直接點擊畫面上的 「Deploy」 藍色按鈕。
  5. 等待撒花： 大約等待 45~60 秒，Vercel 會自動幫您安裝依賴、打包編譯。完成後會噴灑紙片慶祝，並給您一組專屬的網址！

若您準備好要上傳到 GitHub，或是想使用 Vercel CLI 直接從本地終端機部署（免建 GitHub），可以隨時告訴我！
